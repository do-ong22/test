# 돌멩이가 있어도 — 개발용 소스

트라우마의 심리학 수업 소셜 캠페인용 브라우저 미니게임입니다.

- 현재 공개 게임: https://stones-and-steps.goodrun94.chatgpt.site
- 기준 버전: v7 / 내보낸 날짜: 2026-09-24
- 원본 커밋: `d9dc20f59edafa9d4d4c6cbf60439d7fb76aaf5e`

## 빠르게 실행하기

ZIP을 완전히 압축 해제하세요. HTML/CSS/JavaScript로 작성된 정적 웹앱이라 npm 설치나 빌드가 필요하지 않습니다. 별도 백엔드, 데이터베이스, API 키도 필요하지 않습니다.

가장 간단한 개발 방법은 VS Code에서 이 폴더를 열고, Live Server 확장으로 `dist/index.html`을 실행하는 것입니다.

Python이 설치되어 있다면 README가 있는 폴더에서 아래 명령을 실행해도 됩니다.

Windows:

```sh
py -m http.server 8000 --bind 127.0.0.1 --directory dist
```

macOS / Linux:

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory dist
```

브라우저에서 http://127.0.0.1:8000 을 여세요. 서버 종료는 터미널에서 `Ctrl+C`입니다. 최신 Chrome, Edge, Safari 등 현대 브라우저에서 확인하세요.

## 파일 구성

| 파일 | 내용 |
| --- | --- |
| `dist/index.html` | 화면 구조, 캔버스, 버튼, 대화상자 |
| `dist/style.css` | 화면 디자인, 반응형 배치, 머리 위 선택창 |
| `dist/game.js` | 게임 규칙, 상태, 조작, 충돌, 그림과 효과, 스테이지 진행 |
| `dist/assets/comic-01.png` ~ `comic-10.png` | 원본 만화 10장. 일부 그림은 게임 스프라이트로도 사용 |
| `dist/assets/nature-atlas.png` | 나무·잔디·꽃·열매 그림 |

이 프로젝트의 `dist`에는 수정 가능한 원본 코드가 들어 있습니다. 컴파일된 파일이나 축약된 번들이 아닙니다. 파일을 수정하고 브라우저를 새로고침하면 반영됩니다.

## 현재 게임 흐름

- 방향키 또는 A/D로 이동합니다. 모바일은 화면의 이동 버튼 또는 길을 탭합니다. Space/Escape는 일시정지입니다.
- 1 → 2 → 3스테이지 순서로 진행하며, 각 단계가 끝나면 만화가 3장 / 3장 / 4장씩 나옵니다.
- 돌은 피할 수 있습니다. 돌을 만났을 때 캐릭터가 가로·세로 각각 1px 커지고 경험·성장·회복탄력성 등의 단어와 효과가 나옵니다.
- 보호받지 못한 발작버튼에 닿으면 캐릭터가 가로·세로 각각 1px 작아집니다. 게임오버는 없습니다.
- 2·3스테이지에서는 발작버튼을 만나는 타이밍에 H 또는 도움 버튼을 누르면 해당 충돌의 크기 감소를 막습니다. 도움은 자동으로 활성화되지 않습니다.
- 3스테이지에서 돌을 만나면 진행이 멈추고 머리 위에 작은 선택창이 뜹니다. ← 마주하기는 돌의 성장 효과를 적용하고, → 지나가기는 크기 변화 없이 계속 진행합니다. 선택창을 클릭해도 됩니다.
- 3스테이지의 새로운 디딤돌 경로에는 초록 발판이 나옵니다. 발판은 별도의 빛·파동 효과를 주며 캐릭터 크기를 바꾸지 않습니다.
- 배경은 1단계 기본 풍경 → 2단계 나무와 잔디 → 3단계 꽃과 열매로 바뀝니다.

이 게임의 크기와 효과는 캠페인을 위한 상징적 표현입니다. 트라우마가 반드시 성장으로 이어져야 한다는 메시지가 되지 않도록, 지나가기와 쉬어가기 선택도 존중하는 흐름을 유지해 주세요.

### 수정 시 참고

1. 논리 캔버스는 800×700이고, 캐릭터 기본 크기는 47×66입니다. 크기는 가로·세로 함께 변하며 최소 32×51입니다. CSS로 화면에 맞춰 크기를 조정하므로 고해상도·다양한 화면 비율은 별도로 확인하면 좋습니다.
2. 단계 시간은 `[22, 24, 22]`초입니다. 총시간 `68`이 진행률·엔딩·선택적 상태 조회 코드에도 들어 있으므로 `durations`를 변경할 때 함께 확인하세요.
3. 도움 타이밍은 같은 길의 발작버튼 충돌 약 0.65초 전부터 0.45초 후까지입니다. H를 길게 누르는 대신 새로 눌러야 합니다. 요청 한 번은 해당 발작버튼 하나를 보호합니다. 도움 캐릭터가 약 2초 보이는 시간 전체가 무적 시간은 아닙니다.
4. 캐릭터·돌·발작버튼·도움 캐릭터 일부는 만화 원본에서 고정 픽셀 좌표로 잘라 그립니다. 원본 이미지 크기나 배치를 바꾸면 `sourceDraw()` 호출 좌표와 `natureCrops`도 확인하세요.
5. 진행 상태는 메모리에만 있습니다. 새로고침하면 초기화됩니다. `document.modelContext` 연동은 선택적으로 검사하며, 일반 브라우저 실행에는 필요하지 않습니다.
